Maze Rivals support

Pre-release draft. Maze Rivals is not released yet. This page describes how the game is meant to work when it is released, and it will be finalised before then.

Need help? Write to support@firebirdstudio.games. We usually answer within 3 business days.

Please include:

  • the game version (Settings, under About, the Version line),
  • your phone model and its Android or iOS version,
  • what you did, what you expected and what happened,
  • your friend code (Friends screen) if the problem is about your account.

Common questions

I missed a round deadline. If you do not submit in time, your rival gets that round's point. If you miss two turns in the same match, the match is forfeited. Alerts in Settings > Alerts can remind you before a deadline.

A player is bothering me. Open the Friends screen and block them. To report a player's name or behaviour, write to us with their name and, if you have it, their friend code.

I think a result is wrong. Open the round result and tap Watch replay: the game replays both mazes and checks the scores against the server. If it still looks wrong, write to us with the match's rival name and round.

My name was refused or I want to change it again. Names can be changed once a week. Write to us if you need an earlier reset.

I want to delete my account. See https://mazerivals.app/delete-account.

Privacy. See https://mazerivals.app/privacy.
